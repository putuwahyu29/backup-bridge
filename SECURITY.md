# Security Policy

## Supported Versions

Only the latest major and minor release versions receive security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is a top priority for this package. If you discover a security vulnerability within backup-bridge, please follow these guidelines:

1. **Do not create a public GitHub issue.**
2. Send an email to the maintainer at putu.wahyu.dev@gmail.com detailing the vulnerability, including:
   - Steps to reproduce the issue
   - Proof of concept (PoC) code or requests if possible
   - Impact assessment
3. You will receive an acknowledgment within 48 hours.
4. Maintainers will work on a coordinated patch and release a security advisory via GitHub Releases.

Thank you for helping keep the open source community secure!
